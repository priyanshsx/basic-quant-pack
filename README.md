# Quantitative Analysis Pack 

This is a basic quantitative analysis pack that computes returns, daily volatility, log returns (what are they?), rolling volatility for crypto assets. 

- Log returns: for calculating long-term volatility. Rlog = ln(Pt/Pt-1)
- Rolling volatility 
- SMA: 20-day and 50-day 
- Cumulative return
- Max drawdown
